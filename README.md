# project-b-utils

Библиотека утилит для работы с датами, строками, файлами и логированием.

## Установка

```bash
pip install -e .
```

## Модули

- `date_utils`: `get_current_date`, `format_date`, `days_between`, `add_days`
- `string_utils`: `reverse_string`, `capitalize_words`, `truncate`, `slugify`
- `file_utils`: `read_json`, `write_json`
- `logger_utils`: `get_logger`

## Тесты

```bash
python3 -m pytest
```
